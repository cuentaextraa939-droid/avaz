Política de privacidad de A.V.A.Z.

Última actualización: 31 de octubre de 2026

A.V.A.Z. es un asistente personal de uso privado. Esta política explica qué datos de Google usa y cómo los trata.

Quién usa la aplicación

La aplicación la usa únicamente su dueño, con sus propias cuentas de Google. No está abierta al público, no admite registros y no recoge datos de otras personas.

Qué datos de Google usa

  • Google Calendar: eventos del calendario, para consultarlos, crearlos, modificarlos y avisar de los próximos.
  • Google Sheets: el contenido de hojas de cálculo propias, para leer y anotar registros personales.
  • Google Drive: archivos propios, solo cuando el dueño pide trabajar con ellos.
  • Gmail: correos que el dueño indica (por ejemplo, los marcados con una etiqueta de facturas), para leerlos, resumirlos y preparar borradores. La aplicación no envía correos por su cuenta.

Cómo se usan y dónde se guardan

Los datos se procesan con n8n en un servidor propio del dueño. Algunos resultados (por ejemplo, el importe y vencimiento de una factura) se guardan en una base de datos privada del dueño. Para entender el contenido, parte del texto se envía a la API de Google Gemini. Los avisos y respuestas se envían al dueño por Telegram.

Con quién se comparten

Los datos de Google no se venden, no se usan para publicidad y no se comparten con terceros, salvo los servicios técnicos mencionados arriba que el propio dueño usa para hacer funcionar su asistente.

El uso de la información recibida de las APIs de Google cumple la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.

Cómo revocar el acceso

El acceso puede retirarse en cualquier momento desde la página de permisos de la cuenta de Google. Al hacerlo, el asistente deja de poder leer esos datos.
